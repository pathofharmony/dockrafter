# OCR models (RTen)

RTen models for `docrafter-ocr` (same family as [ocrs](https://github.com/robertknight/ocrs)):

- `text-detection.rten`
- `text-recognition.rten`

Download into this directory:

```bash
./scripts/fetch-ocr-models.sh
```

Models are not committed (size); the script and engine live in this repository.
